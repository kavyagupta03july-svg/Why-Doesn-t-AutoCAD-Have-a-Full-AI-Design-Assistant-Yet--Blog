#### Why Doesn't AutoCAD Have a Full AI Design Assistant Yet?

This repository contains the source text, research notes, and supporting visuals for the blog post exploring the barriers to building a truly autonomous AI design assistant for AutoCAD. 

#### Overview

While generative AI has rapidly transformed text, image, and code generation, traditional Computer-Aided Design (CAD) software relies on strict geometric precision and engineering standards. This article examines the core bottlenecks preventing full AI automation in AutoCAD workflows. 

#### Key Topics Covered

* **Precision vs. Probability:** Why probabilistic large language models struggle with deterministic, millimeter-accurate drafting requirements.
* **Legacy Architecture:** The technical constraints of the decades-old .dwg file format and complex object dependencies.
* **Domain Complexity:** The challenges of automating adherence to local building codes, structural tolerances, and industry-specific standards.
* **Current State vs. Future:** A look at existing Autodesk AI tools (like Autodesk Assistant and Markup Assist) versus a true generative co-pilot.
